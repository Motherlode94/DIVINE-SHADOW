# DIVINE SHADOW

Site officiel expérimental de l'univers **CHAYAH VEHUHIA** et **AETHER**. Site indépendant de Base44.

## Lancer

Ouvrir `index.html` dans un navigateur. Aucun build, compte ou dépendance JavaScript requis.

## Structure

- `index.html` : accueil et sections personnages, univers et dialogue.
- `styles.css` : design responsive, palette obsidienne, rouge et cyan.
- `script.js` : fiches personnages et interactions.

## Visuels

Les silhouettes sont des **illustrations CSS temporaires**, explicitement indiquées comme telles. Les vrais portraits et planches de poses de CHAYAH et AETHER ne sont pas intégrés : remplacer ces éléments par des images originales autorisées avant de présenter ce site comme une galerie définitive.

## Hébergement

Compatible avec GitHub Pages (Settings → Pages → Deploy from a branch → main / root) et Cloudflare Pages (déploiement statique sans commande de build, dossier racine `.`). Le déploiement n'est pas activé automatiquement par ce dépôt.
